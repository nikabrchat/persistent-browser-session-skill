# Постоянный аутентифицированный профиль браузера (непрерывность сессии)

*[English version: README.md](README.md)*

Открытый (open-source) Hermes skill, позволяющий агенту продолжать
работу, которую владелец уже сам авторизовал в своей почте Яндекс,
за счёт повторного использования **одного постоянного локального
пользовательского профиля Chromium** между отдельными запусками —
cookies, `localStorage`, `IndexedDB` и состояние service worker
сохраняются так же, как это происходит в обычном браузере человека.

Это **непрерывность сессии** (session continuity), а не подмена
цифрового отпечатка (fingerprint spoofing) и не симуляция
человеческого поведения. Точные и обязательные границы описаны в
разделе "What this is not" файла `SKILL.md`.

## Что делает этот skill

- Поддерживает один профиль Chromium "живым" между запусками агента,
  чтобы владельцу не нужно было входить заново каждый раз.
- По умолчанию доступ к почте **только для чтения** (список/открытие/
  чтение/поиск писем).
- Требует **явное подтверждение человеком для каждого конкретного
  действия** перед отправкой, удалением, перемещением, пересылкой
  письма или изменением настроек.
- Относится к содержимому любого письма — теме, тексту, отправителю,
  ссылкам — как к **недоверенным данным**, а не как к команде, даже
  если текст письма утверждает обратное.
- Ограничивает навигацию небольшим, опубликованным allowlist-ом
  доменов Яндекс Почты (`references/yandex_mail_allowlist.md`).

## Что этот skill намеренно не делает

- Не читает, не запрашивает и не хранит пароль от аккаунта.
- Не участвует в прохождении MFA или CAPTCHA — владелец проходит их
  сам, вручную, каждый раз, когда это требуется.
- Не подменяет отпечатки WebGL/Canvas/TLS, не патчит
  `navigator.webdriver`, не переопределяет User-Agent и не запускает
  никакие stealth-плагины для автоматизации.
- Не решает CAPTCHA, не использует ротацию proxy и не имитирует
  движения мыши или набор текста человеком.
- Не импортирует cookies или токены сессии из других источников.
- Не отключает sandbox Chromium, не запускается от root и не
  публикует CDP ни на каком интерфейсе, кроме `127.0.0.1`.

Подробное обоснование каждого ограничения — в `THREAT_MODEL.md`, а
порядок сообщения о найденной проблеме — в `SECURITY.md`.

## Быстрый старт

```sh
# 1. Один раз: создать директорию профиля (вне Git, права 0700).
#    Запускать от выделенного непривилегированного пользователя,
#    никогда не от root.
scripts/launch_browser.sh --init --profile-dir ~/.persistent-browser-session/yandex-mail

# 2. Один раз (и заново при истечении сессии): владелец входит
#    вручную, включая любой шаг MFA/CAPTCHA.
scripts/launch_browser.sh --interactive --profile-dir ~/.persistent-browser-session/yandex-mail

# 3. При каждом следующем запуске: возобновление уже
#    аутентифицированной сессии.
scripts/launch_browser.sh --profile-dir ~/.persistent-browser-session/yandex-mail
```

Ни один из этих шагов не принимает пароль, cookie или токен — ни как
аргумент, ни как переменную окружения, ни как файл, который этот
skill читает.

## Структура репозитория

| Путь | Назначение |
|---|---|
| `SKILL.md` | Определение skill-а, которое загружают агенты: границы, рабочий процесс, инварианты. |
| `scripts/launch_browser.sh` | Безопасный launcher: проверки root/sandbox/lock/CDP/allowlist, без секретов. |
| `scripts/domain_policy.py` | Проверка allowlist-а доменов Яндекс Почты (офлайн, без сети). |
| `scripts/action_policy.py` | Классификация read-only/mutating и шлюз подтверждения. |
| `scripts/profile_guard.py` | Проверки прав доступа и расположения директории профиля. |
| `scripts/safety_lint.py` | Запрещает anti-detect/credential/network паттерны в коде этого репозитория. |
| `scripts/skill_lint.py` | Проверяет frontmatter `SKILL.md` и обязательные фрагменты про безопасность. |
| `scripts/secret_scan.py` | Детерминированный сканер секретов для этого репозитория. |
| `fixtures/dry_run_session.json` | Синтетическая fixture почтового ящика — без реальных данных. |
| `scripts/dry_run.py` | Прогоняет политики против fixture, офлайн. |
| `tests/` | Набор тестов `unittest` без внешних зависимостей, покрывающий всё вышеперечисленное. |
| `references/` | Allowlist, инструкции по отзыву/выходу из сессии, требования к хранению профиля. |
| `THREAT_MODEL.md`, `SECURITY.md` | Рассмотренные угрозы, исключения и порядок сообщения о проблеме. |

## Запуск тестов и dry-run

```sh
python3 -m unittest discover -s tests -v
python3 scripts/dry_run.py
python3 scripts/secret_scan.py .
```

Всё перечисленное выполняется полностью офлайн на синтетической
fixture — без реального браузера, сетевых запросов и реальных
учётных данных.
